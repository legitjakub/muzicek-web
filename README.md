# Mužíček

Web pro Mužíček Car Detailing v Jablonci nad Nisou. Úvodní rozcestník propojuje tři samostatné části: Auta, Servis a Detailing.

Živá verze: [testmuzicek.netlify.app](https://testmuzicek.netlify.app/)

## Technologie

- Astro
- Sanity CMS
- Netlify

## Lokální vývoj

```sh
npm install
npm run dev
```

Produkční sestavení:

```sh
npm run build
```
