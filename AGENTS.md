## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Safe agent workflow

Work on an `ai/...` branch and prepare a draft pull request. Do not push main, merge, publish Pages, or modify Sanity production data without a separate instruction. Run `npm run build:pages` before committing. Keep tokens out of source and reports. Read-only review cannot replace build checks. For larger changes, first record a proposal, acceptance criteria, and tasks.
