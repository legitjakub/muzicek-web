# Source materials

This directory keeps migration and brand source material separate from production assets.

- `brand/` is a local-only, Git-ignored directory containing the supplied 2026 identity draft and original media files. It is not published in this public repository.
- `legacy-site/` is a reproducible archive of the public Squarespace site generated by `npm run archive:legacy`.
- `PROJECT_CONTEXT.md` is the working map of the Notion brief, brand direction, content model and interaction decisions.

The website should only copy selected, approved and optimized media into `public/`. The legacy archive is evidence and a migration source, not a public asset pipeline.
